Part 2: Bezier surfaces with separable 1D de Casteljau

Bicubic Bezier surfaces are made by taking 4 bezier curves and taking a point on each Bezier curve to create a new bezier curve that spans across the area covered by the four curves. To create a point that sweeps across the entire surface, we can use de Casteljau to find the four points that we are going to use from each curve for the sweeping curve that is going to span the surface. That means that for each of the four Bezier curves of n points, we can do n-1 steps of de Casteljau to get the singular paramtric point for the curves. We do this n times for the n curves that make up the generalized Bezier surface for n^2 loops. When we finally have our parametric curve of n points, that itself a n point Bezier curve we do a final iteration of n-1 de Casteljau loops to get a parametric point that spans the entire smooth Bezier surface. In this implementation it is just running n^2 loops for the n Bezier curves of the surface to get the final curve, and then doing n more de Casteljau loops to get the final point, which follows the same general procedure but in code.

Section II: Triangle Meshes and Half-Edge Data Structure

Part 3: Area-weighted vertex normals

For this case, we take the given vertex and using the algorithm from the Half-Edge primer, we loop around the faces of the vertex by iterating through a series of halfEdge next and halfEdge twin loops to get each face. While we get each face we loop through each of the half edges and call their vertex attributes to get the three vertices of each face adjacent to the given vertex. We calculate their positions, and create two vectors by subtracting the vertices from each other. After that we simply call Vector3D::cross on the two vectors and add them to a sum of vectors to sum them up. After we get the sum of all of the surface normals, we weight them by taking the unit normal of the summed vector by calling Vector::unit to give an averaged sum of the adjacent surface normals to the given vector.
